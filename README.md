# 🧰 Terminal Toolbox

A fun and interactive command-line app built in Bash that installs and launches useful and entertaining Linux terminal tools from a simple menu. This project demonstrates Bash scripting, user input handling, conditionals, and real-world APT package management.

---

## 🚀 Features

- Menu-driven interface with easy navigation
- Installs and launches tools like:
  - `figlet`: ASCII banner generator
  - `cowsay`: Cow that says anything you type 🐄
  - `sl`: Steam locomotive animation 🚂
  - `fortune`: Displays random quotes or jokes
- Uses `apt` for package installation
- Handles invalid input gracefully
- Fully scriptable and customizable

## 💻 How to Run

Make the script executable and run it:

```bash
chmod +x toolbox.sh
./toolbox.sh
```
